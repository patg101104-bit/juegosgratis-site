Balls: Ricochet!

Balls: Ricochet! - an arcade shooting game. The project pays tribute to the memory of old retro gaming. If you consider yourself a true connoisseur of games, you should play this game and immerse yourself in nostalgia. The game will delight you: -Authentic gameplay -Correct ball physics -Good visual design The exciting, addictive gameplay will immerse you in the pursuit of the best score for a long time. The concept, developed in the early 80s, still works perfectly. Start playing and beat your friend's score! Also pay attention to the following parts of the "Balls", have a nice game!

¿Cómo jugar a Balls: Ricochet!?

Your task in the game is to set the direction of the ball. The ball destroys blocks using the environment of the level, you can set the direction of the ball so that it ricochets off the walls and blocks, so in one shot you can knock out several blocks at once.
