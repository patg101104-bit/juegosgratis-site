Red-Blue Forge

Red-Blue Forge is a fast reaction arcade game where you rotate core orbs to match incoming embers and survive as long as possible. Start in classic 2-core mode (Red/Blue), then unlock 4-core mode (Red/Blue/Green/Yellow) for higher intensity and a x3 score multiplier. The game features smooth touch/mouse controls, quick sessions, and a “Ready” start gate so each run begins on your command. Between runs, collected materials feed a persistent Forge Tree progression system. Temper upgrades to improve control, stability, scoring bonuses, and long-run mastery. Every match rewards precision and timing, while long-term progression gives players clear goals and replay value. Ideal for mobile and desktop, Red-Blue Forge combines skill-based gameplay, readable visuals, and satisfying build progression in short, addictive runs.

¿Cómo jugar a Red-Blue Forge?

Tap/click left or right to rotate your core and match the color of incoming embers before they hit the center. Press Ready to start each run, build score by chaining correct matches, and avoid mismatches that end the session. Earn materials from runs, then spend them in the Forge Tree to unlock upgrades and, later, 4-core mode for all four colors and x3 score.
