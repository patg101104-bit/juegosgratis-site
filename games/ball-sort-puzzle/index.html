Ball Sort Puzzle

Someone mixed the balls in the flasks! Put things in order and sort the balls so that each flask contains balls of the same color. There are many challenging levels in this puzzle game, ranging from easy to hard!

¿Cómo jugar a Ball Sort Puzzle?

The control is simple: click the flask from which you need to get the ball, then click the flask where to send it. You will find many exciting levels, built from easy to difficult. A little logic, a little patience, and order will be restored!
