¿Cómo jugar a BMG Crash Test?

Destroy various wheelbarrows on large maps with lots of hammers, crushers, ramps, presses, and obstacles! Controls: TAB - Pause B - Slow down time N - next car Move - WASD Spacebar - Handbrake C - Camera Change For mobile devices use the game interface!
