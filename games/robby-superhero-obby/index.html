Robby Superhero Obby

The game is similar to the popular roblox OBBY mode. Check yourself if you can get to the end by overcoming all obstacles. There are 10 superpowers in the game. On the first map, you will be able to destroy walls. Shrink to a tiny size to fit into small passages. Jump high. Use X-ray vision to see hidden objects. Stop time. On the second map, you can turn off gravity to jump further. Change the angle of gravity to run on walls and ceilings. Use the jetpack to climb higher. Use a protective aura to avoid taking damage. And you can also become invisible. Reach checkpoints, get cups and unlock new skins for your character.

¿Cómo jugar a Robby Superhero Obby?

Your task is to get to the end of the level using different superpowers. If you fall, you will start from the place of the last checkpoint. Control (computer): ● WASD - Movement ● Right Click - Camera Overview ● Space Jump ● Tab or Escape Pause ● Keys 1, 2, 3, 4, 5 - Activating Superpowers Control (phone): ● Using the game interface ● Move in any place - Camera view
