Bubble Merge 2d

Bubble Merge is a relaxing physics-based puzzle game where you combine matching bubbles to create new items and complete each level’s objectives. Plan your moves carefully, use helpful power-ups, and discover new combinations as the challenges become more difficult.

¿Cómo jugar a Bubble Merge 2d?

Tap and drag a bubble to aim. Release to launch the bubble. Merge two identical bubbles to create a higher-level item. Create the items displayed at the top of the screen to complete the level. Finish all objectives before running out of moves. Use power-ups when you need extra help.
