Geek Escape: Run for Survival

Geek Escape: Run for Survival is an exciting arcade game where players control a nerdy hero racing against bullies. Available for free online on various platforms, it combines action and strategy. Players dodge obstacles and use trash cans as weapons in this thrilling adventure filled with excitement.
