Cow Cow Run

A cow was having a nice life, but all changed when the UFO nation came and wants to kidnap the cow. Help the cow avoid the UFOs while collecting coins to buy it’s freedom! Core Gameplay & Story Q: What is the game about? What needs to be done? A: The game is similar to 3D Pacman where you need to escape from aliens while being a cow, to complete a level you need to collect all the coins on the level. ¿Cómo jugar a Cow Cow Run?

Use ASWD or ARROW buttons or CONTROL buttons to move the cow. Upgrades buffs so when you get them ingame, you can use the best buffs!
