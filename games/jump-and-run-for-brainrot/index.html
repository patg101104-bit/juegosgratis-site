Jump And Run For Brainrot

Run and Jump for Brainrot is a fast-paced game where your goal is to collect Brainrot memes and grow stronger. Jump across platforms to gather Brainrot, bring it back to your base, and power up. Level up to jump higher and reach even more challenging areas.

¿Cómo jugar a Jump And Run For Brainrot?

Desktop WASD / Arrow Keys = Move the character Right Mouse Button (hold and drag) = Rotate the camera Spacebar = Jump Left Mouse Button = Attack Q = Drop Brainrot E = Take Brainrot R = Back to base Z = Rebirth P = Settings Tab = Slow mode Mobile Left joystick = Move the character Swipe on the right side of the screen = Rotate the camera Jump button = Jump Attack button = Attack Drop button = Drop Brainrot Take button = Take Brainrot
