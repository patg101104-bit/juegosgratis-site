¿Cómo jugar a Slidey: Sliding Cat Puzzle?

● Slide/move cute cat blocks left or right. ● New rows rise from the bottom with each slide/move. ● Create full lines to make cats disappear. ● Game is over if cat blocks reach the top of the grid.
