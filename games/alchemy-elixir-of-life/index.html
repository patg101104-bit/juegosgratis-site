Alchemy Elixir of Life

Alchemy: Elixir of Life is an exciting puzzle game in which you can feel like a real creator. Create and find all the elements to save your beloved! Find the elixir of life right now! Start with four simple elements — fire, water, earth and air — and create everything that exists in the world. Connect the elements, discover new combinations and watch as order is born out of chaos. Each discovery brings joy, and each new combination brings you closer to solving all the mysteries of the universe. Use logic, imagination and intuition, because there is no single path in alchemy, only your own.

¿Cómo jugar a Alchemy Elixir of Life?

At the beginning, several basic elements are available to you: Water, Land and Air. Choose the first element (for example, Water). Select the second element that you want to add to it (for example, Earth). If there is a combination in the game, then a new element will appear (for example, Water + Earth = Mud). A new item is added to the list, and you can combine it further. Some combinations are obvious (Fire + Water = Steam), while others will require experimentation and logic. Each open element counts, and you gain a certain level in alchemy, as well as getting closer to victory! Sometimes the same result can be obtained in different ways — it all depends on your thinking. Gradually, you will create entire worlds: plants, animals, technology, and even life. The goal of the game is to discover all the combinations, save your beloved and create the elixir of life!
