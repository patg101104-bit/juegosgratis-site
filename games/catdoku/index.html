CatDoku

CatDoku is a cozy logic puzzle with cute cats! Place the fluffy heroes on the board following three simple rules: one cat per row and column, one cat per color, and no cats in adjacent cells. Easy rules — but the further you go, the trickier the levels get.

¿Cómo jugar a CatDoku?

The goal is to place cats on the board so that all three rules are satisfied. CatDoku Rules: 🐾 1 cat per row and column — exactly one cat in each row and each column. 🐾 1 cat per color — exactly one cat in each colored zone. 🐾 Cats are not adjacent — no two cats can be in neighboring cells, including diagonally. How to play: Tap an empty cell to place a cat. Tap it again to remove it. Arrange all the cats so that no rule is broken. Tips: • Look for rows, columns, and colored zones with the fewest empty cells left — start with those. • Once you place a cat, mentally cross out its neighboring cells, as well as its entire row, column, and color. • If you're unsure — use the hint, it will reveal a correct position.
